O Exame Nacional do Ensino Médio (ENEM) é a principal porta de entrada para o ensino superior no Brasil. No entanto, o desempenho dos estudantes muitas vezes reflete variáveis que vão além da sala de aula.



Este projeto utiliza microdados públicos fornecidos pelo INEP (Instituto Nacional de Estudos e Pesquisas Educacionais Anísio Teixeira) para realizar uma análise exploratória de dados (EDA) e investigar como fatores socioeconômicos — tais como renda familiar, escolaridade dos pais, acesso à internet e tipo de escola — influenciam as notas obtidas pelos candidatos nas diferentes áreas do conhecimento e na redação.





Tecnologias e Ferramentas

O projeto foi desenvolvido em Python, utilizando o ecossistema de bibliotecas para análise e manipulação de dados:



Pandas: Limpeza, manipulação e estruturação do grande volume de microdados.



NumPy: Suporte a operações matemáticas e vetoriais de alta performance.



Matplotlib / Seaborn: Criação de visualizações estatísticas e gráficos informativos.
